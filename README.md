Фотохостинг «Со Смыслом» (With Sense) планирует разработать поиск референсных изображений по текстовому запросу. Пользователь описывает нужную сцену, после чего сервис должен находить фотографии с максимально похожим содержанием.

В рамках PoC необходимо разработать модель, которая получает векторное представление изображения и текста и оценивает их соответствие числом от 0 до 1. На основе сравнения нескольких моделей требуется выбрать наиболее эффективную для дальнейшего развития продукта.
